# NeuralOperator FNO Phase 0 Baseline

This is a local smoke artifact for the autoresearch controller. It is not a
vendored copy of the NeuralOperator repository and does not run real PDE
training.

Purpose:

- validate descriptor wiring
- validate allowed implementation paths
- validate artifact archival
- validate canonical benchmark output
- validate metric parsing and gates

The real NeuralOperator integration should replace this baseline with a
controlled checkout/template of https://github.com/neuraloperator/neuraloperator.
